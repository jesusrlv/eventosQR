# EventosQR – QR Code Event Management Platform

## Overview

EventosQR is a web platform developed to manage events using QR code technology.

The system allows event organizers to manage guests, generate QR codes, and control access efficiently.

## Features

* Event management
* QR code generation
* Guest registration
* Access control
* Administrative dashboard

## Technologies Used

* MySQL
* JavaScript
* HTML
